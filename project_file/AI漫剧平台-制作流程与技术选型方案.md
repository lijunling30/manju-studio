# AI 漫剧制作平台 · 制作流程与技术选型方案（PRD 输入文档）

> 版本：v1.1 ｜ 日期：2026-08-03 ｜ 作者：B 哥（项目管理）
> 用途：本文档作为《AI 漫剧制作平台 PRD》的核心输入，覆盖端到端制作流水线、每环节国内大模型 API 推荐、主流技术栈要求与关键架构决策。
> v1.1 变更：合规检验独立为可选模块（步骤 9，用户自选）；成片导出强制携带 AI 生成标识；分镜提示词改为纯中文（与 PRD v1.2 对齐）。

## 1. 产品定位（一句话）

面向中小漫剧团队与个人创作者，提供「AI 小说 → 剧本 → 分镜 → 角色资产 → 多镜头视频 → 配音 → 成片」的一站式 AI 漫剧工业化生产平台，核心价值 = **降本（单分钟成本压到 500-800 元）+ 提效（单集 3-5 天）+ 一致性（跨镜头角色锁定）**。

### 目标用户（MVP 阶段）
| 用户群 | 核心诉求 | 付费能力 |
|---|---|---|
| 一人公司/小团队（5-15 人） | 全流程工具链、角色一致性、成本可控 | 中 |
| MCN/漫剧承制公司 | 批量产能、投流 ROI、模板化 | 高 |
| 网文平台/IP 方 | 网文快速漫剧化改编 | 高 |

---

## 2. 端到端制作流程（9 步总览）

```
阶段一：内容策划与剧本
  1. AI 小说生成 → 2. 剧本结构化 → 3. 分镜设计 → 4. 角色资产库
阶段二：制作与后期
  5. 关键帧生图 → 6. 多镜头视频生成 → 7. 配音与音效 → 8. 剪辑质检成片
阶段三：合规与交付（可选 + 强制）
  9. 合规检验模块（用户可选）＋ 成片导出（强制携带 AI 生成标识）
```

## 3. 分步详解（每步含：目标 / 输入输出 / 推荐国内 API / 技术要点 / 兜底策略）

### 步骤 1：AI 小说生成
- **目标**：基于用户输入（题材、人设、大纲、参考小说）生成完整小说文本，支持续写、扩写、改写。
- **输入**：题材关键词 / 世界观设定 / 主角人设 / 目标章节数。
- **输出**：结构化小说（章节目录、正文、角色表、设定集）。
- **推荐国内 API**：
  - **DeepSeek-V3 / R1**（深度求索）：长文本推理性价比之王，中文叙事能力强，成本低
  - **通义千问 qwen-max / qwen-long**（阿里云百炼）：超长上下文窗口，适合整本小说续写
  - **豆包大模型（火山方舟）**：字节系，网文风格数据训练充分
  - **Kimi（月之暗面）**：长上下文友好
- **技术要点**：分段流式生成 + 章节大纲先行（先生成章纲再逐章扩写），防止长文本漂移；角色表单独维护，供后续一致性绑定。
- **兜底**：生成质量不佳时提供「重新生成/续写/改写」操作，LLM 生成成本极低可多次重试。

### 步骤 2：剧本结构化
- **目标**：将小说文本自动转化为「剧本格式」——分场、分集、对话、旁白、情绪标注、动作描述。
- **输入**：小说章节文本。
- **输出**：JSON 结构化的剧本（scene/character/dialogue/narration/emotion/action），供分镜引擎消费。
- **推荐国内 API**：
  - **DeepSeek-V3**：JSON 输出稳定性好、指令遵循强
  - **通义千问 qwen-plus/max**：函数调用（Function Calling）成熟，适合结构化抽取
  - **智谱 GLM-4-Plus**：中文理解细腻
- **技术要点**：用「结构化输出（JSON Schema）约束」而非自由文本；每场戏标注情绪曲线（爽点/虐点/反转），为投流剪辑提供节奏依据。
- **兜底**：Schema 校验失败自动重试 2 次 + 人工修正入口。

### 步骤 3：分镜设计
- **目标**：把剧本自动拆解为镜头语言：镜头号、景别（特写/近景/中景/远景）、运镜（推拉摇移）、时长、画面描述、对白、旁白、转场。
- **输入**：结构化剧本。
- **输出**：分镜表（shot list，JSON/表格），每镜头含**中文画面提示词** + 运镜指令。
- **推荐国内 API**：
  - **DeepSeek-V3 / qwen-max**：分镜拆解 + 中文提示词生成
  - **即梦/可灵官方分镜工具**（可选接入）：平台自带分镜模板
- **技术要点**：这是**全流程最核心的中间产物**——分镜表同时驱动生图、生视频、配音、剪辑四个环节；提示词生成需带上角色引用 ID（如 `[CHAR:01]`）与风格 ID，确保下游一致；**目标用户仅面向国内，提示词统一为中文，不生成英文提示词**（如个别视频厂商对英文适配更好，由 AI 模型网关后台静默翻译，用户界面不暴露英文）。
- **兜底**：分镜表提供可视化时间线编辑器，允许人工调整镜头顺序与时长。

### 步骤 4：角色资产库（一致性锁定——核心难点）
- **目标**：为每个主要角色建立**统一的视觉资产**，解决行业最大痛点「跨镜头人物不一致」。
- **输入**：角色表（外貌、服饰、性格描述）。
- **输出**：角色三视图/正面像 + 表情包（喜怒哀乐）+ 风格锚点（画风 ID）。
- **推荐国内 API**：
  - **通义万相（文生图/图像编辑）**：人物写真、风格化稳定
  - **即梦 AI 图片生成**：角色形象设计强
  - **豆包图片生成（火山方舟）**：生成速度与一致性平衡好
  - **智谱 CogView-4**：中文提示词文生图
  - **LiblibAI / 哩布哩布**：Stable Diffusion 生态，可训练**角色 LoRA**（一致性终极方案）
- **技术要点**：
  1. 每个角色生成「正面 + 侧面 + 背面 + 表情集」入库；
  2. 视频阶段用 **图生视频（首帧=角色图）+ 首尾帧控制** 锁定形象；
  3. 对高频角色可训练 LoRA（10-20 张图），一致性最好；
  4. 所有下游生图/生视频请求强制引用资产库中的参考图，禁止裸文字生成角色。
- **兜底**：资产库提供「角色换脸/修正」工作流，不满意可局部重绘。

### 步骤 5：关键帧生图
- **目标**：为每个分镜生成高质量关键帧（keyframe）图片，作为视频生成的首帧。
- **输入**：分镜表 + 角色资产 + 场景资产 + 风格锚点。
- **输出**：每镜头 1-N 张候选关键帧（支持多抽卡候选）。
- **推荐国内 API**：
  - **通义万相**：批量文生图稳定、阿里生态计费友好
  - **即梦 / 豆包图片**：画质高、中文审美强
  - **Vidu 参考图能力**：主体一致性增强
- **技术要点**：**抽卡管理**——每镜头生成 2-3 张候选，AI 自动评分（构图/一致性/清晰度）+ 人工选择，合格帧进入下一步；抽卡日志入库用于成本核算。
- **兜底**：候选池不够可一键「再抽一轮」。

### 步骤 6：多镜头视频生成（核心引擎）
- **目标**：将关键帧动态化为多镜头视频片段（图生视频），支持运镜与口型。
- **输入**：关键帧 + 运镜指令 + 时长 + 角色引用。
- **输出**：每镜头一段 4-10 秒短视频（mp4），统一分辨率/帧率。
- **推荐国内 API（五大主力，按需选 2-3 家聚合）**：
  | 厂商 | 模型 | 优势 | 适合场景 |
  |---|---|---|---|
  | 快手 | **可灵 Kling 2.0** | 画质最好、动作自然 | 精品成片 |
  | 字节 | **豆包 Seedance 2.0 / 即梦** | 性价比高、声画同出、构图强 | 批量生产 |
  | 生数科技 | **Vidu 2.0 / Q3** | 角色一致性最强、参考生视频、商用影视级 | 漫剧主力（强烈推荐） |
  | 阿里 | **通义万相 Wan2.x** | 阿里云生态、API 成熟 | 存量云客户 |
  | MiniMax | **Video-01** | 写实风格 | 仿真人漫剧 |
- **技术要点（重要）**：
  - **视频 API 全是异步任务模式**：提交任务 → 轮询/回调 → 拿结果，必须自建「任务编排层」统一管理多家异步任务；
  - 用**图生视频**而非纯文生视频（保证与关键帧一致）；
  - 可用**首尾帧控制**（Vidu/可灵支持）实现镜头衔接连续；
  - 竖屏 9:16（1080×1920）为主 + 横屏 16:9 备选，统一编码 H.264。
- **兜底**：生成失败/翻车自动重试（限流降级切换厂商）；提供「抽卡 + 人工筛选」交互，**不要承诺一键成片**。

### 步骤 7：配音与音效
- **目标**：为镜头生成角色配音（多音色 TTS）+ 背景音乐 + 音效。
- **输入**：对白文本 + 角色音色配置 + 场景情绪。
- **输出**：配音音频轨（按镜头对齐）+ BGM + 音效轨。
- **推荐国内 API**：
  - **火山引擎豆包 TTS（音色克隆/多情感）**：音色库丰富、情感自然，业界标杆
  - **阿里云 CosyVoice / 通义听悟**：声音克隆、多语言
  - **MiniMax 语音**：高自然度 TTS
  - **智谱 GLM-4-Voice**：端到端语音
  - **天工 SkyMusic（昆仑万维）/ 网易天音**：AI 音乐/BGM 生成
- **技术要点**：每个角色绑定固定音色 ID（配音一致性）；对白按时间轴对齐镜头；BGM 按情绪段自动匹配合成；输出多轨音频（对白/BGM/音效分离）便于剪辑。
- **兜底**：提供音色试听与替换，情绪不对可单独重录某句。

### 步骤 8：剪辑质检成片
- **目标**：将视频片段 + 音频 + 字幕 + 转场合成为最终成片，并输出多平台规格版本。
- **输入**：镜头视频片段 + 音轨 + 字幕文本。
- **输出**：完整成片（mp4）+ 平台规格版本（抖音 9:16 / B 站 16:9 / 横竖版）——**所有导出成片强制携带 AI 生成标识**（见步骤 9）。
- **推荐国内 API/能力**：
  - **FFmpeg**（自建渲染服务）：拼接、转场、字幕烧录、转码——基础设施
  - **阿里云视频点播 / 腾讯云点播**：云端转码、分发 CDN
  - **剪映开放能力（可选）**：模板化剪辑
  - **AI 字幕**：阿里 Paraformer / 讯飞 ASR（自动生成字幕并校准）
- **技术要点**：字幕自动生成 + 关键词高亮样式；**AI 生成内容标识（显式角标 + 元数据水印）为强制项，导出成片一律携带**（依据《生成式人工智能服务管理暂行办法》《AI 生成合成内容标识办法》）；内容安全审核不在此步骤强制——见步骤 9「合规检验模块（用户可选）」。
- **兜底**：提供云端时间线编辑器，人工精修后重新渲染。

### 步骤 9：合规检验模块（用户可选）＋ 导出强制标识
- **目标**：将「内容安全审核、版权/IP 校验」等合规能力**独立为可选模块**，由用户自行选择是否启用；同时保证**成片导出必须携带 AI 生成标识**。
- **输入**：成片 + 用户选择（是否启用合规检验）。
- **输出**：审核报告（通过/未通过 + 违规定位）/ 无检验版本（仅带 AI 标识）。
- **合规检验（用户可选启用）**：
  - 内容安全审核：**阿里云内容安全 / 腾讯云天御 / 网易易盾**——文本 + 画面 + 音频多模态检测；
  - 版权/IP 校验：网文改编项目可校验授权来源（项目创建时声明授权信息）；
  - 交互：导出前弹窗让用户选择「执行合规检验」或「跳过（仅带 AI 标识导出）」；执行检验时，**机器审核 → 可疑内容人工复核 → 出具审核报告**，通过后才允许分发到公开平台；
  - 检后可补：已导出的成片可随时「补做检验」生成报告，无需重新渲染。
- **强制项（不可关闭）**：无论是否启用合规检验，**所有导出成片必须携带 AI 生成标识**（显式角标 + 元数据水印），这是平台合规底线，无开关。
- **技术要点**：合规检验作为独立任务接入任务编排层（L3），不影响主流水线；审核报告结构化入库，供项目档案查询。
- **兜底**：审核服务不可用时提示「检验不可用，可选择跳过或稍后补检」，导出功能不被审核服务故障阻塞（AI 标识不受影响）。

| 环节 | 首选 | 备选 | 备注 |

## 5. 主流技术栈要求（架构建议）

### 5.1 总体架构
```
[前端工作台 Web] → [应用服务层 API] → [任务编排/工作流引擎] → [AI 模型网关(多厂商聚合)] → [各家大模型 API]
                                          ↓
                              [资产库/分镜库/任务库] → [对象存储] → [渲染服务 FFmpeg] → [CDN/分发]
```

### 5.2 技术选型
| 层 | 推荐 | 说明 |
|---|---|---|
| 前端 | **Next.js 14+ / Vue3 + Nuxt**、Tailwind CSS、Monaco 编辑器（剧本/分镜编辑）、Konva/Fabric（时间线画布） | 云端工作台 |
| 后端 | **Python FastAPI**（AI 生态友好）或 **Node.js NestJS** | 业务 API |
| 任务编排 | **Celery + Redis**（起步）→ 进阶 **Temporal / Argo Workflows**（DAG 化流水线） | 视频生成异步任务管理的核心 |
| AI 网关 | **自研模型网关**（或 OneAPI/New API 二次开发）：统一鉴权、限流、重试、多厂商路由、成本记账 | **关键自建组件** |
| 数据库 | PostgreSQL（业务数据 + pgvector 向量检索） | 分镜/角色/任务元数据 |
| 向量库 | pgvector / Milvus | 角色描述、分镜语义检索 |
| 对象存储 | 阿里云 OSS / 腾讯 COS / MinIO（私有化） | 图片/视频/音频资产 |
| 消息队列 | Redis Streams / RabbitMQ | 异步任务解耦 |
| 渲染 | FFmpeg（容器化，GPU 可选）+ 云点播转码 | 拼接成片 |
| 部署 | Docker + K8s（或云容器服务）、CI/CD（GitLab CI/GitHub Actions） | 生产环境 |
| 监控 | Prometheus + Grafana + Sentry | 任务成功率、成本、错误追踪 |

### 5.3 必须自建的三个核心组件（PRD 中的重点）
1. **AI 模型网关**：统一封装所有大模型 API，屏蔽异步任务差异，支持厂商路由/降级/重试/成本账单——这是平台的技术护城河；
2. **角色资产库 + 一致性引擎**：角色参考图、LoRA、风格锚点的集中管理与下游强制引用；
3. **任务编排引擎**：分镜→生图→生视频→配音→剪辑的 DAG 流水线，支持断点续跑与失败重试（视频任务单个可能 1-10 分钟）。

## 6. 关键架构决策与风险提示（PM 视角）

1. **「抽卡管理」是产品交互核心**：所有生成环节提供「批量候选 + AI 评分 + 人工选择 + 再抽一轮」，**不要承诺一键成片**（行业已验证：同一 prompt 两次生成结果不同）。
2. **视频生成选 2-3 家聚合**：可灵/豆包/Vidu 各有强项，避免单厂商依赖；不同厂商计费模型差异大，网关内做成本对比。
3. **角色一致性是 MVP 成败指标**：建议把 Vidu（参考生视频/首尾帧）作为视频主力模型验证一致性。
4. **合规分层设计**：AI 生成标识为**强制项**（导出成片一律携带，无开关）；内容安全审核与版权/IP 校验做成**用户可选模块**（步骤 9），由用户自主决定是否启用，平台在导出前给出明确选择入口；注意：若平台对公分发内容，内容安全仍是平台运营义务，建议对「公开分发」场景默认开启校验、仅对「内部预览/自用导出」允许跳过（评审时确认）。
5. **成本模型**：文本环节成本可忽略；大头是视频生成（单镜头约 0.5-3 元不等，按分辨率/时长计费）。产品计费需按「生成次数/算力消耗」而非「成片数量」定价。
