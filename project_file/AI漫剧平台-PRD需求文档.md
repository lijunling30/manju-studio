## 第一层 · 为什么做

## 1. 背景与机会

### 1.1 行业背景
- **市场规模**：2025 年国内漫剧全年流水预计达真人短剧市场的 1/3，全年规模有望突破 **200 亿元**；广义微短剧 2025 年产值预估接近 **900 亿元**。
- **供给爆发**：企查查数据显示，2025 年全年累计注册漫剧相关企业 **8.02 万家**，同比增长 **37.1%**；DataEye 数据显示，2026 年 2 月末在播 AI 剧/漫剧总量已达 **12.78 万部**。
- **供给增速**：2025 上半年漫剧供给/播放/点赞月度复合增长率分别为 83% / 92% / 105%。

### 1.2 用户痛点（已核实，非推测）
1. **人物/场景跨镜一致性差**：被业内公认的「最大技术痛点」，同一角色在不同镜头间形象漂移、崩脸；
2. **抽卡随机性高**：单段分镜常需 20+ 次重试，浪费算力与时间；
3. **长叙事稳定性差**：AI 视频超过 1 分钟即崩坏，专业团队仍要大量返工；
4. **跨工具工作流断裂**：剧本/分镜/生图/视频/剪辑分散在不同平台，人力成本是大头；
5. **爆款率极低、同质化严重**：新剧「破亿率」仅 0.117%，内卷压缩利润空间；
6. **算力计费粗糙**：无统一的角色库/分镜库/资产库与成本对账体系。

### 1.3 机会窗口
- 行业正从「拼速度」转向「卷内容、卷质量」，**工业化生产工具链**是下一步分水岭；
- 头部平台（抖音/快手/B 站/阅文）均在扶持 AI 漫剧，流量与分成政策友好；
- 现有工具（即梦、可灵等）只解决「单点生成」，**全流程一体化 + 一致性 + 成本可控**的产品仍是空白。

### 1.4 商业机会
| 变现路径 | 说明 |
|---|---|
| SaaS 订阅 | 按席位 + 功能套餐（个人版 / 团队版 / 企业版） |
| 算力消耗计费 | 按生成次数/算力消耗收费（非按成片数） |
| B 端定制 | 品牌广告、出版机构、游戏公司定制 AI 漫剧 |
| IP 生态 | 与网文平台合作改编分成、IP 衍生 |

## 2. 用户与场景

### 2.1 目标用户
| 用户群 | 核心诉求 | 付费能力 | 优先级 |
|---|---|---|---|
| 一人公司 / 小团队（5-15 人） | 全流程工具链、角色一致性、成本可控 | 中 | P0 |
| MCN / 漫剧承制公司 | 批量产能、投流 ROI、模板化 | 高 | P1 |
| 网文平台 / IP 方 | 网文快速漫剧化改编 | 高 | P2 |

### 2.2 用户画像（Persona）
**主画像 · 「一人公司」小雨**
- 背景：95 后，前幼儿园老师，现自由职业，团队 1 人；
- 现状：用通义千问写剧本 → 通义万相生角色图 → 可灵做视频 → 剪映剪辑，**4 个工具来回切换，同一角色每次生成都不一样**；
- 诉求：一个平台走完全流程；同一角色跨镜头不变脸；知道每集花了多少钱；
- 付费意愿：单集成本 < 1000 元可接受；月预算 2000-5000 元。

**次画像 · 承制公司主理人**
- 背景：5-15 人团队，月产 20-50 部漫剧，走平台分账 + 投流；
- 诉求：批量产能、任务失败自动重试、成本按项目对账、投流 ROI 数据回流。

### 2.3 核心使用场景
**场景 A（主流程）**：用户输入题材 → AI 生成小说 → 自动拆剧本 → 自动分镜 → 设定角色 → 批量生成关键帧（抽卡）→ 逐镜头生成视频 → 配音配乐 → 自动剪辑 → 审核 → 导出成片 → 一键发布。

**场景 B（人工精修）**：用户在任意中间环节介入调整（改分镜、换关键帧、换音色、调时间线），平台基于修改点增量重生成，不推倒重来。

**场景 C（B 端定制）**：品牌方上传产品图与调性描述，平台生成品牌专属漫剧广告，输出多版本。

## 3. 竞品分析

| 竞品 | 类型 | 优势 | 劣势 | 对我们的启示 |
|---|---|---|---|---|
| 即梦 AI / 豆包（字节） | 单点生成工具 | 画质高、构图强、声画同出 | 只解决单点生成；>1 分钟叙事崩；不支持真人人脸参考 | 全流程一体化是差异点 |
| 可灵 Kling 2.0（快手） | 单点生成工具 | 画质最好、动作自然 | 无剧本/分镜/剪辑一体化 | 质量对标可灵 |
| 通义万相（阿里） | 单点生成工具 | API 成熟、阿里生态 | 无工作流 | 复用其 API 能力 |
| 漫剧助手（阅文） | IP 改编工具 | 网文 IP 资源 | 绑定阅文生态，非开放平台 | 差异化：不绑 IP，服务创作者 |
| 纳米漫剧流水线（360） | 流程工具 | 单集制作压缩至 1 小时 | 偏内部工具，未形成开放产品 | 流程自动化程度是我们的参照 |

**差异化定位**：竞品解决「单点生成」，漫镜工场解决「**从小说到成片的完整工业化流水线 + 跨镜头角色一致性 + 成本可视化**」。

## 4. 产品定位与目标

### 4.1 一句话定位
面向中小漫剧团队与个人创作者的一站式 AI 漫剧工业化生产平台，让「小说 → 成片」全流程在一个工作台完成。

### 4.2 核心价值主张
- **降本**：单分钟成片 API 成本 ≤ 500 元（含抽卡损耗）；
- **提效**：单集（60 镜头）端到端全自动 ≤ 24 小时；
- **一致性**：同一角色跨 20 镜头一致性通过率 ≥ 80%；
- **可控**：成本可查询、可对账、可设预算上限。

### 4.3 核心指标（OKR 视角）
| 类型 | 指标 | 目标值（MVP 期） |
|---|---|---|
| 北极星 | 平台月产成片集数 | ≥ 500 集 |
| 辅助 | 单分钟 API 成本 | ≤ 500 元 |
| 辅助 | 角色一致性通过率 | ≥ 80% |
| 辅助 | 视频生成任务成功率 | ≥ 95% |
| 辅助 | 单集端到端时效 | ≤ 24 小时 |
| 辅助 | 付费用户月留存 | ≥ 30% |

### 4.4 非目标（MVP 明确不做）
- 不做移动端原生 App（仅 Web 响应式）；
- 不做自研视频大模型（全部调用厂商 API）；
- 不做复杂的多租户计费体系（MVP 仅按项目记账）；
- 不做 AI 仿真人剧（先聚焦 AI 漫剧品类）。

## 第二层 · 做什么

## 5. 功能需求

> 需求编号规则：FR-Module-序号；优先级 P0（MVP 必须）/ P1（应有，可延后到 M2/M3）/ P2（可以有）。

### 5.0 模块总览
| 模块 | 核心职责 | MVP 优先级 |
|---|---|---|
| M1 项目管理 | 项目/剧集/资产的组织 | P0 |
| M2 AI 小说生成 | 文本生成、续写、改写 | P0 |
| M3 剧本结构化 | 小说→剧本、分场分集 | P0 |
| M4 分镜设计 | 剧本→镜头语言 | P0 |
| M5 角色资产库 | 角色形象、一致性锁定 | P0 |
| M6 关键帧生图 | 分镜→候选关键帧 | P0 |
| M7 多镜头视频生成 | 关键帧→镜头视频 | P0 |
| M8 配音与音效 | TTS、BGM、音效 | P1 |
| M9 剪辑与质检 | 时间线、合成、导出（AI 标识强制） | P0 |
| M10 用户与计费 | 账号、套餐、账单 | P1 |
| M11 投流对接 | 平台发布与数据回流 | P2 |
| M12 角色 LoRA 训练 | 一致性进阶能力 | P2 |
| M13 合规检验模块 | 内容安全审核/版权校验（用户可选） | P0 |

> **全局标注**：M2-M8 及 M12 等所有「调用 AI 模型」的模块，**均须遵循 5.0.1「AI 需求确认闸口」全局交互原则**，不再逐模块重复描述。

### 5.0.1 全局交互原则 · AI 需求确认闸口（P0 ★全局）
**原则**：用户发起任何 AI 生成/编辑/续写请求时，**AI 必须先结构化复述自己对需求的理解并预估成本，经用户明确确认后，才真正执行任务**。未确认前不产生任何算力消耗。

**适用模块（全部 AI 调用场景）**：M2 小说生成、M3 剧本结构化、M4 分镜设计、M5 角色形象、M6 关键帧、M7 视频生成、M8 配音配乐、M12 LoRA 训练，以及后续所有新增 AI 能力。

**交互流程（确认闸口）**：
```
用户发起请求 → AI 结构化复述需求（意图 / 输入解析 / 输出物 / 预估成本）
  → 展示「确认卡」弹窗（含关键参数摘要 + 成本预估 + 可编辑项）
  → 用户「确认」→ 进入任务编排执行；用户「修改」→ 回到复述步骤循环；
  → 用户「放弃/超时（60s）」→ 默认不执行，不产生任何费用
```

**确认卡内容要求**：
1. **意图复述**：用一句自然语言总结「用户想让 AI 做什么」（如「为第 3 章生成 20 个分镜镜头」）；
2. **参数摘要**：展示关键入参（题材/角色引用/风格/镜头数/时长等），便于用户核对；
3. **成本预估**：预估本次生成的费用区间与算力消耗（接入成本模型 A-2）；
4. **可编辑项**：用户可直接在确认卡上修改参数后重新确认（替代「全流程重新输入」）。

**异常处理**：
- 确认超时（60 秒未操作）→ 自动取消，任务状态置 cancelled，不消耗额度；
- AI 复述与用户原意偏差 → 用户选择「修改」，进入修正对话（最多 3 轮，仍无法对齐则转人工引导）；
- 断网/页面刷新 → 未确认的任务保持 pending 状态，不自动执行。

**闸口开关（P0 · 可关闭）**：
- **设计目的**：兼顾「防止误生成浪费成本」与「重复操作效率」——当用户连续多次执行同类低风险操作（如反复抽卡挑选关键帧）时，每次弹确认卡会打断创作流，故提供「关闭开关」提升体验；
- **开关位置**：确认卡左下角「本次会话不再确认（关闭闸口）」复选框 + 全局设置页「确认闸口」开关；
- **开关粒度**：
  - **按模块/场景**：可单独关闭「抽卡/关键帧」等重复操作的确认（高频场景），其他高成本操作（整集视频生成、LoRA 训练）默认保持确认；
  - **按会话**：关闭后仅当前浏览器会话有效，刷新/下次登录默认恢复开启；
  - **全局**：可在设置页永久关闭（谨慎提示「关闭后将不再预检，可能产生未预期的生成费用」）；
- **成本护栏**：即使闸口关闭，**单次超过阈值（如 ≥ 50 元）或批量任务（如 ≥ 20 镜头）仍强制确认**，避免误操作产生大额费用；
- **恢复入口**：任务中心顶部常驻「闸口已关闭」状态徽章，点击可一键恢复开启。

### 5.1 M1 项目管理（P0）
**功能描述**：用户创建/管理漫剧项目，项目内组织剧集、分镜、资产与任务。
- 项目 CRUD、项目信息（题材、风格锚点、目标平台）；
- 项目内资产聚合视图（角色、场景、分镜、成片）；
- 项目级成本统计与预算上限设置；
- 团队协作（邀请成员、角色权限）⚠️ 是否 MVP 需要多人协作，待确认。

**异常处理**：项目删除二次确认；预算超限强提醒。

### 5.2 M2 AI 小说生成（P0）
**功能描述**：基于用户输入生成完整小说文本，支持续写/扩写/改写。
- 输入：题材关键词、世界观设定、主角人设、目标章节数、参考大纲；
- 生成策略：章节大纲先行 → 逐章扩写（防止长文本漂移）；
- 输出：章节目录 + 正文 + 角色表 + 设定集；
- 交互：流式输出、段落级重新生成、锁定已确认段落后再续写；
- 默认引擎：DeepSeek-V3（备选 qwen-max / 豆包）。

**异常处理**：生成中断自动续传；用户可「放弃重来」。

### 5.3 M3 剧本结构化（P0）
**功能描述**：小说文本自动转剧本格式，结构化输出供分镜引擎消费。
- 输出 JSON Schema：`scene / character / dialogue / narration / emotion / action`；
- 自动分场分集，标注每场情绪曲线（爽点/虐点/反转）；
- 编辑器：剧本结构可视化，支持人工修正后重新结构化（增量）；
- 默认引擎：qwen-plus（Function Calling）+ DeepSeek 兜底。

**异常处理**：JSON Schema 校验失败自动重试 2 次，仍失败转人工修正。

### 5.4 M4 分镜设计（P0）
**功能描述**：剧本自动拆解为镜头语言，产出全流程核心中间产物——分镜表。
- 输出字段：镜头号、景别（特写/近景/中景/远景）、运镜（推拉摇移）、时长、画面描述、对白、旁白、转场；
- 每镜头自动生成**中文画面提示词**，**强制携带角色引用 ID（`[CHAR:01]`）与风格 ID**；
- **纯中文提示词（面向国内用户）**：目标用户仅面向国内，分镜提示词统一使用中文，不生成英文提示词；如个别视频厂商对英文提示词适配更好，由 AI 模型网关在后台静默完成翻译，**用户界面全程不暴露英文提示词**；
- 分镜表可视化时间线编辑器，支持拖拽调整顺序/时长、增删镜头；
- 默认引擎：DeepSeek-V3 / qwen-max。

**异常处理**：分镜表与剧本变更联动；删除镜头需确认（下游资产联动）。

### 5.5 M5 角色资产库（P0 ★核心）
**功能描述**：为每个角色建立统一视觉资产，解决「跨镜头人物不一致」；支持按项目管理的人物子库。
- **人物子库（按项目管理）**：用户可创建多个「人物子库」，每个子库独立管理一组角色资产，支持：
  - 按项目建库（如「《我在末世开超市》人物库」「《总裁的AI女友》人物库」），一个账号可维护多个项目的人物库互不干扰；
  - 子库内角色支持增删改、排序、归档；子库可重命名、复制（复制整组角色到新库）、删除（需二次确认）；
  - 同一子库可被多个项目引用（共享角色），也支持项目级私有子库；
  - 子库维度权限：⚠️ 团队场景下子库可设置为私有/共享，待确认（见 Q8）；
- 角色表维护（外貌/服饰/性格 → 绑定视觉形象）；
- 生成角色三视图 + 表情集（喜怒哀乐），默认引擎：即梦 / 通义万相；
- 风格锚点（画风 ID）统一管理，项目级全局生效；
- **强制约束**：下游所有生图/生视频请求必须引用资产库参考图，禁止裸文字生成角色；
- 角色形象不满意 → 局部重绘 / 换脸修正工作流。

**异常处理**：角色图与风格不符 → 提供「按风格重新生成」操作；删除子库二次确认，且子库内角色被下游镜头引用时给出引用清单提示。

### 5.6 M6 关键帧生图（P0）
**功能描述**：为每个分镜生成 2-3 张候选关键帧，作为视频生成首帧。
- 输入：分镜表 + 角色资产 + 场景资产 + 风格锚点；
- **抽卡管理**：批量生成候选 → AI 自动评分（构图/一致性/清晰度）→ 人工选择 → 可「再抽一轮」；
- 场景资产复用：常用场景入库，二次生成直接引用；
- 默认引擎：通义万相 / 即梦（Vidu 参考图能力增强一致性）。

**异常处理**：候选池全部不合格 → 一键批量重抽；抽卡日志入库用于成本核算。

### 5.7 M7 多镜头视频生成（P0 ★核心引擎）
**功能描述**：将关键帧动态化为多镜头视频片段（图生视频）。
- 输入：关键帧 + 运镜指令 + 时长 + 角色引用；
- 输出：每镜头 4-10 秒 mp4，竖屏 9:16（1080×1920）为主，横屏 16:9 备选，H.264 编码；
- **多厂商聚合**：主 Vidu Q3（一致性）+ 备豆包 Seedance 2.0（性价比），可灵 2.0 按需接入；
- **异步任务全生命周期**：提交 → 轮询/回调 → 结果入库 → 失败自动重试（指数退避）→ 主厂商失败自动切换备选；
- 首尾帧控制（Vidu/可灵支持）实现镜头衔接连续。

**异常处理**：超时/翻车自动重试；同一镜头最多重试 3 次，仍失败标记「人工介入」。

### 5.8 M8 配音与音效（P1）
**功能描述**：为镜头生成角色配音、背景音乐与音效。
- 角色绑定固定音色 ID（配音一致性），支持音色试听/替换/情绪选择；
- 对白按时间轴对齐镜头；BGM 按情绪段自动匹配（天工 SkyMusic / 网易天音）；
- 输出多轨音频（对白/BGM/音效分离），便于剪辑；
- 默认引擎：火山豆包 TTS（备 CosyVoice、MiniMax 语音）。

**异常处理**：单句重录不影响其他音轨。

### 5.9 M9 剪辑与质检（P0）
**功能描述**：视频片段 + 音频 + 字幕 + 转场合成最终成片，完成多平台导出（**成片强制携带 AI 生成标识**）。
- 云端时间线编辑器（Konva 画布）：镜头拖拽、转场、字幕样式；
- 自动字幕生成（阿里 Paraformer）+ 关键词高亮；
- **自动合成**：FFmpeg 渲染，输出多平台规格（抖音 9:16 / B 站 16:9）；
- **AI 生成内容标识（强制，无开关）**：所有导出成片强制添加（显式角标 + 元数据水印，依据《生成式人工智能服务管理暂行办法》《AI 生成合成内容标识办法》）；
- **内容安全审核不在本模块强制**：由 M13 合规检验模块（用户可选）承载，导出前由用户自行选择是否启用。

**异常处理**：渲染失败重试；AI 标识烧录失败则禁止导出（强制项不可缺失）。

### 5.10 M13 合规检验模块（P0 · 用户可选）
**功能描述**：将内容安全审核、版权/IP 校验独立为可选模块，由用户自行选择是否启用；导出成片的 AI 生成标识为强制项（不属于本模块开关范围）。
- **用户选择入口**：导出前弹窗「执行合规检验 / 跳过（仅带 AI 标识导出）」；
- **内容安全审核**（启用后）：阿里云内容安全 / 腾讯云天御 / 网易易盾，文本 + 画面 + 音频多模态检测；机器审核 → 可疑内容人工复核 → 出具审核报告；
- **版权/IP 校验**（启用后）：网文改编项目校验授权来源（项目创建时声明授权信息 ⚠️ 具体流程待法务定稿）；
- **公开分发建议**：⚠️ 若用户选择「发布到公开平台」，建议默认强制开启合规检验（内容安全是平台运营义务），仅「内部预览/自用导出」允许跳过——评审时确认（见 Q15）；
- **报告与补检**：审核报告结构化入库供项目档案查询；已导出成片可随时补做检验，无需重新渲染；
- **故障兜底**：审核服务不可用时提示「检验暂不可用，可选择跳过或稍后补检」，不阻塞导出（AI 标识不受影响）。

**异常处理**：审核未通过 → 定位到具体镜头与时间点，支持局部重做后重新送审。

### 5.10 M10 用户与计费（P1）
**功能描述**：账号体系、套餐、算力消耗计费与账单。
- 注册/登录（手机号/微信 ⚠️ 待确认）、RBAC 角色（创作者/管理员）；
- 套餐：个人版 / 团队版 / 企业版；
- **成本记账**：每次生成记录 token/时长/金额，按项目与镜头维度出账单；
- 预算上限设置与超限提醒。

**异常处理**：余额不足拦截生成并引导充值。

### 5.11 M11 投流对接（P2）
**功能描述**：一键发布到平台 + 数据回流。
- 抖音/快手/红果/B 站发布接口对接；
- 播放/分账数据回流到项目仪表盘。

### 5.12 M12 角色 LoRA 训练（P2）
**功能描述**：对高频角色训练 LoRA（10-20 张图），提升一致性上限。
- LiblibAI / 自建 SD 训练管道；
- LoRA 版本管理，可随时切换生效版本。

## 6. 业务流程

### 6.1 端到端主流程（时序）
```
用户 → ①创建项目 → ②AI生成小说 → ③转剧本 → ④分镜设计 → ⑤角色资产
     → ⑥关键帧生图(抽卡) → ⑦多镜头视频(异步) → ⑧配音配乐 → ⑨剪辑合成
     → ⑩合规检验（M13，用户可选）→ ⑪导出成片（AI 标识强制）→ ⑫发布平台
每个环节均支持人工介入 → 增量重生成（不推倒重来）
每个 AI 调用环节均经过「需求确认闸口」（5.0.1），确认后任务才进入队列
```

### 6.2 生成任务状态机（核心对象：AI 生成请求 / 镜头生成任务）
```
【确认闸口阶段（新增）】
draft（AI 复述需求，等待确认）
  → confirmed（用户确认）→ queued（进入队列）
  → rejected（用户修改）→ draft（AI 重新复述，最多 3 轮）
  → timeout / cancelled（60s 未确认或用户放弃，不产生费用）
  → bypassed（闸口已关闭：会话级/模块级跳过；或高成本/批量任务强制确认例外）→ queued

【执行阶段（原状态机）】
queued → running → success
                  └→ failed → retrying → running（指数退避，≤3 次）
                  └→ failed(3次) → manual_review（人工介入）
running 中用户可 cancel → cancelled
success → keyframe_candidate（关键帧）→ approved（人工确认）→ video_generating → …
```

> 闸口开关规则：默认开启；「会话级关闭」仅当前会话有效；「模块级关闭」可针对抽卡等高频场景；即使关闭，单次 ≥50 元或批量 ≥20 镜头的任务仍强制确认（详见 5.0.1 闸口开关）。

### 6.3 异常流程
- **AI 需求理解偏差**：确认闸口「修改」→ AI 重新复述 → 最多 3 轮 → 转人工引导（5.0.1）；
- **抽卡不满意**：候选池重抽 → 人工改提示词 → 换厂商生成；
- **视频生成失败**：自动重试 → 自动切换备选厂商 → 人工介入；
- **审核驳回**：定位镜头 → 局部重做 → 重新合成 → 重新送审；
- **预算超限**：生成前拦截 + 强提醒 + 可临时调额。

## 8. 非功能需求

### 8.1 性能
| 指标 | 要求 |
|---|---|
| 端到端时效 | 单集（60 镜头）全自动 ≤ 24 小时 |
| 文本生成 | 小说章节流式首字响应 ≤ 3 秒 |
| 关键帧生成 | 单镜头候选批量（3 张）≤ 5 分钟 |
| 视频生成 | 单镜头（4-10 秒）任务完成 ≤ 15 分钟（含排队） |
| 页面加载 | 首屏 ≤ 3 秒（P95） |

### 8.2 稳定性
- 视频生成任务成功率 ≥ 95%（含自动重试与降级）；
- 任务失败自动重试 ≤ 3 次，主厂商失败自动切备选；
- 系统可用性 ≥ 99.5%（月度）。

### 8.3 安全
- 厂商 API Key 加密存储（KMS），不落前端、不落日志；
- 用户数据与生成资产隔离，操作审计可追溯；
- 接口鉴权：JWT + RBAC；大文件上传走 OSS STS 直传。

### 8.4 合规（分层设计：强制项 + 用户可选模块）
**强制项（无开关）**：
- 所有导出成片强制添加 **AI 生成内容标识**（显式角标 + 元数据水印，依据《生成式人工智能服务管理暂行办法》《AI 生成合成内容标识办法》）——平台合规底线，任何导出场景不可缺失；
- 用户隐私：手机号等个人信息加密存储，符合《个人信息保护法》。

**用户可选（M13 合规检验模块）**：
- 内容安全审核：阿里云内容安全 / 腾讯云天御 / 网易易盾，机器审核 + 人工复核，由用户导出前自选是否启用；
- 网文 IP 改编授权校验：项目创建时声明授权来源 ⚠️ 具体授权流程待法务确认；
- ⚠️ 公开分发场景建议默认强制开启校验（内容安全是平台运营义务），仅内部预览/自用允许跳过（见 Q15）。

### 8.5 兼容性
- 浏览器：Chrome / Edge 最新两个大版本，Safari 最新版；
- 分辨率适配：桌面优先，支持 1280×800 起。

### 8.6 界面与交互体验需求（P0 · 高端质感）
**设计目标**：平台界面与交互达到「高端、有吸引力、专业创作工具」水准——让用户第一眼就感受到这是**专业的影视级创作工作台**，而非普通 SaaS 后台。界面质感与交互体验是平台吸引与留存用户的核心竞争力之一。

#### 8.6.1 视觉风格定位
- **基调**：沉浸式「暗色影院级」工作台（默认深色主题）+ 亮色可选主题（跟随系统），以内容（分镜画面/视频/角色图）为视觉主体；
- **质感关键词**：深邃、克制、精致、电影感——大面积深色底 + 高对比内容区 + 克制的渐变与光效点缀；
- **色彩体系**：主色（品牌色，建议青紫渐变系「镜光紫 #7F77DD → 电光青 #1D9E75」备选）、功能色（成功/警告/错误）、语义色（成本预警/审核状态）；统一由设计 Token 管理；
- **字体**：中文正文使用系统字体栈（PingFang / Microsoft YaHei）+ 数字/英文使用等宽或几何字体（体现专业感）；标题可引入「影视感」衬线/展示字体（如思源宋体）强化品牌记忆点；
- **动效原则**：克制而有质感——页面过渡、弹层、候选帧对比采用 200-400ms 缓动曲线（cubic-bezier(0.16,1,0.3,1)），所有动效 60fps，尊重 `prefers-reduced-motion`；
- **质感细节**：玻璃拟态浮层（backdrop-blur）、微光晕、细腻阴影、圆角体系（8/12/16px）、1px 高光描边，用于「确认卡」「抽卡九宫格」「成本悬浮卡」等关键交互。

#### 8.6.2 关键页面设计标准
| 页面 | 高端设计要点 |
|---|---|
| 登录/首屏 | 沉浸式品牌视觉（渐变粒子/作品墙背景），登录后即进入工作台而非静态后台 |
| 项目工作台 | 深色三栏布局：项目列表（左）+ 制作流程导航（中）+ 资产/任务面板（右）；流程步骤可视化进度条 |
| 剧本编辑器 | Monaco 深色主题 + 剧本结构大纲树 + 分场/情绪曲线可视化（数据驱动的信息设计） |
| 分镜时间线 | Konva 画布，镜头卡片化（缩略图 + 时长 + 状态色点），拖拽排序带弹性动效，支持批量选择 |
| 角色资产库 | 人物子库导航（左）+ 角色卡片墙（三视图/表情集展示），风格统一，选中态带品牌色光晕 |
| 抽卡候选九宫格 | 大图预览 + AI 评分徽章 + 对比模式（左右分屏/差异放大），选择后过渡动画入时间线 |
| 确认卡（5.0.1） | 居中浮层（玻璃拟态）：意图复述、参数摘要、成本预估（醒目配色）、确认/修改按钮 |
| 任务进度 | 全局任务中心（顶部悬浮）：实时进度条 + 状态图标 + 预估剩余时间，失败可一键重试/换厂商 |
| 成片导出 | 成片播放器（影院式黑场）+ 平台规格选择 + 审核状态徽章 |

#### 8.6.3 交互体验要求
- **减少跳转**：核心操作（生成/抽卡/确认）尽量在当前页浮层/面板完成，不打断创作流；
- **可撤销**：所有破坏性操作支持撤销（Ctrl+Z / 面包屑撤销），删除资产二次确认；
- **实时反馈**：AI 任务全流程可视化（确认→排队→生成→完成），任何等待不超过 15 分钟不给出进度反馈；
- **快捷键体系**：常用操作（生成、抽卡、确认、播放、保存）提供快捷键并支持自定义；
- **空状态与引导**：每个模块首次进入提供高端质感的空状态插画 + 3 步快速引导（结合「一人公司」模板化引导 Q5）；
- **无障碍**：对比度满足 WCAG 2.1 AA，键盘可完整操作，动效可关闭。

#### 8.6.4 设计交付物（进入开发前必须产出）
1. 设计系统/组件库（Figma）：色彩 Token、字体、图标集、组件规范；
2. 高保真原型（覆盖 8.6.2 全部关键页面 + 确认卡 + 抽卡交互）；
3. 交互动效规范（时长/缓动/触发条件）；
4. 响应式规则（1280/1440/1920 三档断点）。

| A-5 | 成本控制 | 单分钟成片 API 成本 ≤ 500 元（含重试与抽卡损耗），每镜头成本可查询可对账 |

| A-7 | 需求确认闸口 | 全部 AI 调用先复述需求并经用户确认后才执行；未确认/超时不产生费用；确认卡含意图/参数/成本预估；**闸口开关可用**（会话级/模块级关闭生效，高成本/批量任务仍强制确认，关闭状态有恢复入口） |
| A-8 | 高端界面交互 | 8.6 全部关键页面按设计标准实现；深色主题为主；核心动效 60fps；抽卡九宫格与确认卡交互完整可用 |

### 9.2 性能验收
- 单集（60 镜头）全自动 ≤ 24 小时；
- 视频任务单镜头 ≤ 15 分钟（P95）。

### 9.3 发布准入条件
- A-1 ~ A-8 全部通过；
- 至少 5 个真实用户完成端到端试用（Beta 阶段），且对界面质感/流畅度的满意度 ≥ 4 分（5 分制）；
- 合规检验模块（M13）在生产环境验证通过（含用户自选启用/跳过链路，AI 标识强制烧录）；
- 无 P0/P1 级缺陷遗留。

## 附 A：AI 专项需求（区别于传统 PRD）

### A-1 抽卡管理设计（P0）
- **原则**：所有生成环节提供「批量候选 + AI 评分 + 人工选择 + 再抽一轮」，**不承诺一键成片**；
- 候选池：关键帧 2-3 张 / 视频 2 段；
- AI 评分维度：构图、角色一致性、清晰度、风格匹配（权重可配置）；
- 抽卡日志：记录每次生成（prompt、厂商、成本、是否采用），用于成本核算与质量分析；
- 交互：九宫格对比选择、差异放大、历史候选保留；
- **抽卡与闸口联动**：连续抽卡为高频重复操作，用户可关闭确认闸口（会话级/模块级，见 5.0.1），关闭后抽卡直接执行、不打断创作流；单次高成本或批量任务仍强制确认。

### A-2 成本模型（P0）
- 计费维度：文本按 token；图片按张数/分辨率；视频按时长/分辨率；TTS 按字符；
- 记账粒度：镜头级（cost_log 表），汇总到项目级/用户级；
- 定价策略：平台按「生成消耗」计费（套餐内包含算力额度，超量按量计费），**不按成片数定价**；
- 预算控制：项目预算上限 → 达 80% 预警 → 达 100% 拦截。

### A-3 合规与安全（P0 · 分层：强制 + 可选）
**强制项（不可关闭）**：
- AI 生成内容标识（显式角标 + 元数据水印）：所有导出成片一律携带，无开关。

**可选模块（M13，用户自选）**：
- 内容安全审核链路：机器审核（阿里云内容安全）→ 可疑内容人工复核 → 出具审核报告；
- 版权校验：项目创建时声明 IP 授权来源，改编类项目可启用校验 ⚠️ 流程待法务定稿；
- 公开分发建议：发布到公开平台默认开启校验（平台运营义务），内部预览/自用可跳过（见 Q15）。

**数据安全（强制）**：厂商 Key 加密、生成资产私有访问（STS 签名）、操作审计日志。

### A-4 需求确认闸口设计（P0 · 全局，详见 5.0.1）
- **触发**：所有 AI 生成/编辑/续写请求（M2-M8、M12 及未来新增 AI 能力）；
- **AI 复述格式**：`意图（一句话） + 参数摘要（结构化键值） + 输出物描述 + 成本预估（区间 + 算力消耗）`；
- **确认卡 UI**：玻璃拟态居中浮层，含「确认 / 修改 / 放弃」三态 + 左下角「关闭闸口」开关；修改进入对话循环（≤3 轮）；
- **闸口开关**：会话级（仅当前会话）+ 模块级（如抽卡场景）+ 全局（设置页，谨慎提示）；关闭后高成本/批量任务仍强制确认（单次 ≥50 元 或 批量 ≥20 镜头）；
- **成本护栏**：确认前不调用任何付费接口；超时（60s）自动取消；
- **数据落库**：ai_request 表全量记录（含每次确认/驳回/成本预估），用于「确认通过率」指标与成本审计；
- **指标**：确认闸口覆盖率 100%（所有 AI 调用必经或显式 bypass 记录），确认前零计费。
