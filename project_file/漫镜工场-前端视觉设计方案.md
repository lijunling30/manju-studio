## 1. 设计概念总述

**设计理念：「镜面工作室（Mirror Studio）」**
把整个平台塑造成一块「可交互的电影镜面」——深色深邃的工作底、镜光般的品牌渐变、内容（角色/分镜/成片）像投在镜面上的影像一样成为视觉主体。核心感受：**走进一个专业的影视级数字工作室，而非打开一个后台系统。**

- **高端感来源**：克制的深色 + 高对比内容 + 精致的微光细节，避免「花哨」；
- **辨识度来源**：青紫渐变「镜光」品牌色 + 独特的镜头/分镜/抽卡图标语言 + 影院式黑场过渡；
- **易用性来源**：一切操作在浮层/面板内完成，不打断创作流（呼应 8.6.3「减少跳转」）。

## 2. 色彩体系（双主题）

### 2.1 设计 Token（CSS Variables）
```
:root[data-theme="dark"] {           /* 默认：影院级深色 */
  --bg-base: #0B0E1A;                /* 深邃太空蓝黑，工作底 */
  --bg-surface: #12162B;             /* 卡片面 */
  --bg-elevated: #1A1F38;            /* 浮层/弹窗 */
  --bg-glass: rgba(26,31,56,0.72);   /* 玻璃拟态 */
  --text-primary: #F2F4FF;
  --text-secondary: #A8AFCC;
  --text-tertiary: #6B7295;
  --brand-purple: #7F77DD;           /* 镜光紫 */
  --brand-teal: #1D9E75;             /* 电光青 */
  --brand-blue: #378ADD;             /* 荧幕蓝 */
  --brand-gradient: linear-gradient(135deg,#7F77DD 0%,#1D9E75 100%);
  --success: #3B6D11; --warning: #854F0B; --danger: #A32D2D; --info: #185FA5;
  --border-subtle: rgba(242,244,255,0.10);
  --border-strong: rgba(242,244,255,0.24);
}
:root[data-theme="light"] {          /* 可选：亮色主题（跟随系统） */
  --bg-base: #F5F6FB;  --bg-surface: #FFFFFF;  --bg-elevated: #FFFFFF;
  --text-primary: #16182B;  --text-secondary: #4A4F6B;  --text-tertiary: #8A90AC;
  --border-subtle: rgba(22,24,43,0.08);  --border-strong: rgba(22,24,43,0.18);
  /* 品牌色/语义色与深色共享，微调明度保证 AA 对比度 */
}
```

### 2.2 色彩使用规则
- **深色为主题，亮色为跟随系统可切换**（默认深色，呼应 PRD Q11 默认）；
- 品牌渐变仅用于：品牌 LOGO、主按钮 hover、选中态光晕、进度条高亮——**克制使用**，大面积留深色；
- 语义色只表达状态：生成完成（青绿）、成本预警（琥珀）、任务失败（红）、审核状态（蓝），统一配 8% 透明底 + 1px 描边徽章；
- 对比度：正文 ≥ 4.5:1（WCAG AA），大标题 ≥ 3:1。

## 3. 字体体系

| 用途 | 字体 | 规格 |
|---|---|---|
| 品牌展示（Logo/首屏/大标题） | 思源宋体（Source Han Serif） | 600/700，可放大至 28-40px，影视感衬线 |
| 中文正文 | PingFang SC / Microsoft YaHei | 13px / 400，行高 1.6 |
| 页面标题 H1 | 系统黑体 | 15px / 500 |
| 区块标题 H2 | 系统黑体 | 14px / 500 |
| 辅助/徽章 Caption | 系统黑体 | 11px / 400，60% 不透明 |
| 数字/英文 | JetBrains Mono（等宽） | 成本、指标、破亿率、时间戳——突出专业感 |

**字体加载策略**：思源宋体按需加载（仅登录页/品牌区），正文用系统字体栈避免性能损耗；数字强制等宽避免抖动（成本/进度数字跳动时尤其重要）。

## 4. 间距与布局体系

### 4.1 间距刻度
`4 / 8 / 12 / 16 / 24 / 32px`——组件内部用 px（8-16px），区块节奏用 rem（1rem=16px 基准）。

### 4.2 圆角体系
- 8px：按钮、输入框、小元素；
- 12px：卡片、面板（默认）；
- 16px：浮层、确认卡、大图预览；
- 999px：徽章、标签、头像。

### 4.3 工作台三栏布局（P-02 核心骨架）
```
┌────────┬─────────────────────────────┬──────────────┐
│ 左栏    │ 中栏（创作主区）              │ 右栏          │
│ 200px  │ 弹性 1fr                    │ 280px        │
│ 项目列表│ 页面内容（随路由切换）         │ 资产/任务面板  │
│ 流程导航│ 深色画布 + 内容为主体          │ 成本/状态      │
└────────┴─────────────────────────────┴──────────────┘
```
- 左栏：项目树 + 9 步流程进度（步骤可视化，呼应 6.1 流程）；
- 右栏：上下文面板——当前镜头的资产引用、成本小计、任务状态；
- 1280px 以下右栏折叠为抽屉，1440/1920 三档断点（呼应 8.6.4）。

## 6. 动效语言

### 6.1 动效规范（Token）
```
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);   /* 标准缓出 */
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1); /* 弹簧弹性（确认卡） */
--dur-micro: 200ms;   /* hover/按压/徽章 */
--dur-mid: 300ms;     /* 弹层/抽屉/候选对比 */
--dur-page: 400ms;    /* 页面切换 */
```
所有动效 60fps（只用 transform/opacity），`prefers-reduced-motion` 时全部关闭。

### 6.2 关键动效设计
| 场景 | 动效 | 说明 |
|---|---|---|
| 页面切换 | 「镜面滑动」 | 新页轻微上移 8px + 透明度 0→1，旧页淡出，400ms |
| 任务完成 | 微光扫过 | 进度条/卡片顶部一道品牌渐变光从左到右扫过（1 次） |
| 抽卡结果 | 3D 翻牌 | 候选帧卡片 Y 轴翻转入场，翻牌后显示 AI 评分徽章 |
| 确认卡 | 弹簧缩放 | 居中浮层从 0.92→1 弹性弹出（spring），遮罩 200ms 淡入 |
| 拖拽排序 | 弹性吸附 | 分镜卡片拖拽时弹性缩放 + 目标位平滑让位 |
| 成本变化 | 数字滚动 | 成本/预算数字增减时等宽滚动动画 |

## 7. 关键页面交互设计（分块详述）

### P-01 登录 / 首屏
- **视觉**：深色品牌墙（青紫渐变粒子 + 精选作品轮播作为背景），中央 LOGO「漫镜工场」思源宋体大字 + 渐变描边；
- **交互**：登录后直接进入工作台（无中间引导页）；首登弹「3 步快速引导」浮层（新建项目 → 生成小说 → 出片预览），可跳过；
- **响应式**：移动端简化为品牌图 + 表单卡片。

### P-02 项目工作台（三栏）
- **左栏**：项目列表（卡片式，封面缩略图 + 名称 + 进度）+ 9 步流程导航（当前步骤高亮品牌渐变）；
- **中栏**：路由内容区，页面切换走「镜面滑动」过渡；
- **右栏**：资产引用面板（当前选中镜头的角色/场景引用缩略图）+ 项目成本小计（等宽数字）+ 任务状态；
- **微交互**：新建项目按钮 hover 渐变填充 + 轻微上浮；项目卡片选中态品牌色光晕描边。

### P-03 剧本编辑器
- **布局**：左「剧本大纲树」（场景/场次层级，Monaco 同源风格）+ 右「正文编辑器」（Monaco 深色主题，JSON 高亮）+ 底部「情绪曲线」（数据可视化：爽点/虐点/反转，SVG 折线，悬停显示场次）；
- **交互**：大纲树点击定位正文；正文段落 hover 显示「重新生成/锁定」按钮；确认闸口在此生效——点「AI 生成」先弹确认卡；
- **快捷键**：Ctrl+S 保存、Ctrl+Enter 触发 AI、Ctrl+Z 撤销。

### P-04 分镜时间线
- **布局**：Konva 画布横向时间轴，镜头卡片（缩略图 + 时长 + 状态色点），底部缩略比例尺；
- **交互**：拖拽排序（弹性让位）、框选批量、双击编辑镜头属性（景别/运镜/时长下拉）、镜头状态色点（待生成/已确认/生成中/失败）；
- **确认闸口**：批量生成时确认卡显示「本次将生成 N 个镜头，预估成本 ¥X」；
- **状态徽章**：顶部悬浮「闸口已关闭」徽章可一键恢复。

### P-05 角色资产库（人物子库）
- **布局**：左侧人物子库导航（可新建/重命名/复制/归档，选中态品牌渐变条）+ 右侧角色卡片墙（网格 3-5 列，每卡：三视图/表情集横向滚动 + 角色名 + 状态）；
- **交互**：卡片 hover 微浮 + 光晕；点击弹出角色详情抽屉（大图 + 表情集 + LoRA 版本 + 引用项目数）；新建角色走确认卡（先复述角色设定 + 预估成本）；
- **空状态**：子库无角色时显示高端插画 + 「创建第一个角色」按钮。

### P-06 关键帧抽卡（九宫格）
- **布局**：大图预览区（选中帧放大）+ 候选九宫格（2-3 张 + 「再抽一轮」）— 每张卡：画面 + AI 评分徽章（构图/一致性/清晰度）+ 选中态品牌光晕；
- **交互**：点击进入「对比模式」（左右分屏 + 差异放大）；确认选择后卡片过渡动画入时间线；
- **确认闸口联动**：连续抽卡可关闸口（5.0.1），关闭后抽卡直接执行。

### P-07 视频生成面板
- **布局**：右栏面板（或独立页）：厂商选择（Vidu/豆包/可灵 Tab）+ 参数（时长/分辨率/运镜/首尾帧）+ 预览窗口；
- **交互**：厂商 Tab 切换实时显示价格与预估（等宽数字）；「生成」触发确认卡（成本预估 + 厂商选择）；任务进行中面板顶部进度条 + WebSocket 实时推送。

### P-08 配音与音效面板
- **布局**：音轨时间线（对白/BGM/音效三轨）+ 角色音色卡（试听按钮）+ 情绪选择下拉；
- **交互**：点音色卡试听（hls 短音频），选中品牌光晕；对白可单句重录；BGM 按情绪段自动匹配预览。

### P-09 剪辑台
- **布局**：顶部预览播放器（影院式黑场）+ 中部时间线（Konva，镜头/字幕/音频轨）+ 底部素材库（镜头片段/音效/转场）；
- **交互**：拖拽素材入时间线；字幕自动生成后可编辑样式（关键词高亮）；「合成成片」→ 确认卡（预估渲染时间 + 平台规格选择）；**导出强制带 AI 标识**（不可关闭，导出按钮旁常驻「AI 标识」徽章）。

### P-10 合规检验面板（M13）
- **布局**：导出前浮层：合规检验选项卡（「执行合规检验」推荐 / 「跳过，仅带 AI 标识」）+ 若执行：审核进度 + 报告；
- **交互**：默认选中「执行检验」（推荐态）；跳过需二次确认文案提示；审核结果状态徽章（通过/驳回+定位镜头）；补检入口在成片卡片上常驻。

### P-11 确认卡（全局浮层 · 玻璃拟态）
- **视觉**：居中 16px 圆角玻璃拟态浮层（backdrop-blur + 1px 高光描边），四区：意图复述（一句话）+ 参数摘要（键值格）+ 成本预估（品牌色等宽大字 + 区间）+ 操作（确认/修改/放弃）；
- **交互**：弹簧缩放弹出；左下角「本次会话不再确认」开关（5.0.1）；60s 未操作自动收起并提示「已取消，未产生费用」；
- **高成本护栏**：单次 ≥50 元 或 ≥20 镜头时确认卡顶部出现「大额任务」警示条。

### P-12 全局任务中心
- **位置**：顶部悬浮（非 fixed，滚动时收纳为胶囊）；
- **内容**：进行中任务列表（缩略图 + 进度条 + 预估剩余 + 状态图标），失败任务「重试/换厂商」按钮；「闸口已关闭」徽章常驻可一键恢复。

### P-13 成本中心
- **布局**：项目成本总览（指标卡：总消耗/预算/剩余/单分钟成本）+ 按镜头/模块的成本明细表（等宽数字）+ 预算滑杆；
- **交互**：达 80% 预算顶部琥珀预警条；达 100% 生成前拦截 + 弹窗提示。

### P-14 设置页
- **分区**：主题（深色/亮色/跟随系统）、确认闸口（三档开关 + 恢复入口）、快捷键（可自定义）、账号与套餐；
- **交互**：开关组件品牌色；主题切换即时生效并带 200ms 渐变过渡。

| shadcn 组件 | **调整** | Button/Card/Badge/Modal 按设计 Token 定制（深色默认） |

### 8.3 关键实现要点
1. **深色主题是默认态**：所有组件先按深色设计，亮色通过 Token 覆盖（不用两套组件）；
2. **WebSocket 驱动任务中心**：`useTaskStore` 订阅任务状态，进度条/徽章实时更新；
3. **确认闸口全局化**：抽成 `<ConfirmGate>` 高阶封装（`useConfirmGate()` hook），任何 AI 操作调 `gate.request({...})` 即可，统一 5.0.1 逻辑；
4. **性能**：分镜时间线/Konva 画布用虚拟化 + 离屏渲染；候选大图懒加载（IntersectionObserver）；hls.js 分片播放；
5. **无障碍**：键盘全操作、焦点环（品牌色 2px）、对比度 AA、动效可关。
